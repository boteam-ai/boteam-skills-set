# Growth playbook (post-launch)

Tactics to compound GitHub stars and useful forks — without spam.

## Week 1 — Launch

- [ ] GitHub Release v1.0.0 with skill tree summary
- [ ] X thread from [marketing/x-thread-launch.md](../marketing/x-thread-launch.md)
- [ ] Show HN from [marketing/hn-show-post.md](../marketing/hn-show-post.md)
- [ ] Record 90s demo per [marketing/demo-script.md](../marketing/demo-script.md)

## Ongoing

| Loop | Action |
|------|--------|
| **BiP** | `/bip` after shipping — link repo when relevant |
| **Workflow of the week** | GitHub Discussion or issue with one playbook from `docs/workflows/` |
| **Awesome lists** | PR to awesome-cursor-rules / awesome-claude-skills after v1.0 stable |
| **Community utilities** | Accept PRs for utility skills; core experts need SOURCES + rubric |

## Metrics that matter

- Clones + forks (intent)
- Issues with reproduction (quality signal)
- External mentions linking workflows (not just stars)

## Do not

- Astroturf stars
- Add core experts without SOURCES.md
- Merge product code into this repo
