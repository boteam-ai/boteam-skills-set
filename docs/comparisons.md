# Comparisons

Honest positioning vs popular skill collections.

| Dimension | boteam-skills-set | [claude-skills](https://github.com/alirezarezvani/claude-skills) | Generic awesome lists |
|-----------|-------------------|-------------------------------------------------------------------|------------------------|
| **Focus** | Solo founder end-to-end | Broad enterprise + personas | Catalog / links |
| **Depth** | Four-piece: SKILL + SOUL + SOURCES + EVALUATION | Varies by skill | Usually prompt-only |
| **Org loop** | `/hire-expert`, `/hr-review`, `/clevel` | No | No |
| **Handoffs** | Explicit expert routing | Ad hoc | None |
| **Install** | Symlink SSOT + ship gate | Copy skills | Copy skills |
| **Size** | ~15 core + utilities | 1000+ skills | 100s entries |

## When to use us

- You are **one person** wearing strategy + product + eng + GTM hats
- You want **named experts with personas**, not anonymous prompts
- You want a **skill tree** and workflows, not a flat list to search

## When to use claude-skills instead

- You need a niche enterprise skill we do not ship
- You want maximum breadth over solo-founder coherence

## We stand on their shoulders

Core experts distill MIT-licensed upstream libraries. Every expert cites sources in `SOURCES.md`. See [attribution.md](attribution.md).
