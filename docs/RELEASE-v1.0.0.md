Initial public release of **boteam-skills-set**.

Strategy · Product · Engineering · GTM · HR meta — each with SKILL + SOUL + SOURCES + EVALUATION.

`/hire-expert` · `/hr-review` · `/clevel` · `/distill-to-team`

### Platform utilities

`/setup` · `/qa-review` · `/refine` · `/lesson` · `/bip` · `/headline` · `/help-skills`

### Entry command

**`/boteam`** — full expert roster and division of labor.

## Install

```bash
git clone https://github.com/boteam-ai/boteam-skills-set.git
cd boteam-skills-set
chmod +x scripts/*.sh
./scripts/install-skills.sh --global --shipped-only
```

Then **`/boteam`** in any Cursor or Claude Code session.
