# Workflow: Build in public

**Goal:** Turn shipping into audience compounding without performative noise.

## Steps

| # | Invoke | Output |
|---|--------|--------|
| 1 | `/bip` | Platform-native post from recent ship work |
| 2 | `/headline` | Headline options if launch moment |
| 3 | `/social-media-manager` | Calendar + repurpose plan |

## Done when

- [ ] One authentic post shipped (with real lesson, not vanity metrics)
- [ ] Humanizer pass on `/bip` output complete
- [ ] Next post scheduled with specific ship milestone

## Loop

Ship feature → `/bip` → engage → `/researcher` for audience feedback → product
