# Workflow: Validate an idea

**Goal:** Decide whether to build, pivot, or kill — before writing product code.

## Steps

| # | Invoke | Output |
|---|--------|--------|
| 1 | `/researcher` | Interview plan, demand signals, competitive map |
| 2 | `/product-manager` | MVP scope from validated problem only |
| 3 | `/ceo-founder-coach` | Go / pivot / kill memo with kill conditions |

## Done when

- [ ] At least one behavioral demand signal (not compliments)
- [ ] MVP fits one week of solo build time
- [ ] CEO coach names the single riskiest assumption for week 1
