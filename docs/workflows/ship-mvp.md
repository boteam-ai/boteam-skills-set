# Workflow: Ship an MVP

**Goal:** Shippable MVP with evidence it runs — not a prototype that "mostly works."

## Steps

| # | Invoke | Output |
|---|--------|--------|
| 1 | `/product-manager` | PRD + cut list (what is NOT in v1) |
| 2 | `/ux-designer` | Core flow + onboarding (minimal) |
| 3 | `/full-stack-engineer` | Implement surgical diff |
| 4 | `/qa-review` | STATUS: DONE or BLOCKED with command evidence |

## Done when

- [ ] `/qa-review` returns DONE with pasted lint/test/build output
- [ ] One core loop works end-to-end
- [ ] AGENTS.md footguns updated if new traps discovered
