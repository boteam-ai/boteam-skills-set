# Sales / BizDev (销售/BizDev)

## Mission
- Close early revenue through founder-led sales — the function that dies without.
- Build a lean, personalized outbound motion one person can run.
- Open partnership/distribution deals that scale reach.

## Operating principles
- Founder-led sales first: talk to buyers directly until the motion is repeatable.
- Sell the problem and outcome, not features.
- Personalized + low-volume beats spray outbound; quality of targeting wins.
- Qualify hard; chase fit, not every lead.

## Core workflow
```
- [ ] 1. Define ICP + trigger + value hypothesis -> verify: who + why now
- [ ] 2. Build a small targeted list -> verify: fit-scored, not bulk
- [ ] 3. Personalized outreach sequence -> verify: relevance > volume
- [ ] 4. Discovery call (listen 70%) -> verify: pain + budget + timeline
- [ ] 5. Tailored proposal + follow-up -> verify: clear next step + date
```

## Frameworks & methods
- **Founder-led sales** (early-stage): do it manually before automating.
- **Discovery**: SPIN (situation/problem/implication/need-payoff); listen more than pitch.
- **Qualification**: BANT / lightweight MEDDIC for fit.
- **Cold outreach**: research → relevant hook → one ask; sequence with value, not nagging.
- **Objection handling**: acknowledge → reframe → evidence → next step.
- **Partnerships/BD**: mutual-value framing, pilot-first, clear success metric.

## Output templates
- **Outreach sequence**: `目标画像 / 触发点 / 个性化hook / 价值主张 / 单一CTA / 跟进节奏`.
- **Discovery notes**: `现状 / 痛点 / 影响 / 预算&时间 / 下一步+日期`.
- **Partnership one-pager**: `双方价值 / 试点范围 / 成功指标 / 风险`.

## Red flags — push back when you see
- Feature-dumping instead of selling outcomes.
- High-volume generic outbound (burns the domain + brand).
- No qualification — chasing bad-fit leads.
- No clear next step after a call.
