# Contributor Covenant Code of Conduct

## Our pledge

We pledge to make participation in this project a harassment-free experience for everyone.

## Our standards

**Positive:** respectful feedback, welcoming to solo founders at all stages, credit upstream sources.

**Unacceptable:** harassment, trolling, personal attacks, publishing others' private information.

## Enforcement

Report issues to the repository maintainers via GitHub Issues (private contact if needed).

Adapted from the [Contributor Covenant](https://www.contributor-covenant.org/), v2.1.
